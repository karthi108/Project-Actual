# Evidence-linked improvement proposals

IMPLEMENTED; canonical acceptance PENDING.

The engine links each review judgment to exact owner-scoped observed session events. Missing, conflicting or wrong-activity evidence fails. Closed reviewed bases support elimination, simplification, scoped API integration, deterministic copying, bounded AI assistance or human work. Consequential or uncertain judgments remain human. The ordering follows elimination/simplification/integration/deterministic before AI; there is no automatic preference for a model.

Every result carries source references, a digest of observations/review, provenance, reasoning and mandatory review; it executes nothing. A review may propose removing redundant output, but repeated activity alone does not prove a step unnecessary. Human claims and synthetic design reviews are labeled and never become policy or independent factual verification. No recommended career facts or existing application materials are changed.

Matched explicit synthetic workload measurements can report differences in supplied active time, elapsed time, failures, intervention and model calls. Missing active time stays unmeasured. No time-saving estimate, ROI, monetary cost or real performance claim is inferred from trace gaps.

Tests cover mechanism order, consequence preservation, evidence rejection and matched/missing measurements. Real improvement validity, intervention/compute measurement and human judgment quality remain canonical validation debt.
